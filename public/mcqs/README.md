```
public/mcqs/
├── work-energy-power-mcq-practice.pdf   <-- 20 Verified EAPCET MCQs with step-by-step solutions
├── laws-of-motion-mcq-practice.pdf     <-- (Future chapter)
└── gravitation-mcq-practice.pdf         <-- (Future chapter)
```

---

## 🚀 How to Add New MCQ PDFs

1. Drop the MCQ PDF directly into `public/mcqs/`.
2. Extract the questions into `src/data/<chapter>-questions.json` following the verified schema.
3. Once deployed, the PDF will be directly accessible at:
   `https://<your-username>.github.io/eapcet-physics-platform/mcqs/<filename>.pdf`

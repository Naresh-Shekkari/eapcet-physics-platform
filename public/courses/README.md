# Course Content & Learning Materials Directory

This folder is dedicated to **Complete Course Materials, Theory Notes, Formulas, and Lecture Guides** for each chapter.

---

## 📁 Recommended Folder Structure

```
public/courses/
├── work-energy-power/
│   ├── work-energy-power-theory-notes.pdf     <-- Comprehensive chapter theory notes
│   ├── formula-sheet.pdf                      <-- Quick formula revision sheet
│   └── syllabus-breakdown.pdf                 <-- Chapter topic roadmap
│
├── laws-of-motion/                            <-- Future chapters
│   └── laws-of-motion-notes.pdf
│
└── gravitation/
    └── gravitation-notes.pdf
```

---

## 🚀 How to Add Course Content

1. Create a folder for your chapter under `public/courses/<chapter-slug>/` (e.g., `work-energy-power`).
2. Drop your PDF files (theory notes, formula sheets, mind maps) into that folder.
3. Once deployed, these files are automatically available at:
   `https://<your-username>.github.io/eapcet-physics-platform/courses/<chapter-slug>/<filename>.pdf`
4. The website UI will display these study materials alongside the chapter practice quizzes.
